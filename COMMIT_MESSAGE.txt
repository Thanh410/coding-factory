fix(runner): exit non-zero when run-loop leaves a task blocked or failed

The scheduled loop returned 0 no matter what happened to a task, so a run where
every agent attempt failed reported success. That is exactly how the broken
codex default stayed invisible: the run was green while no branch and no PR were
produced.

run_loop now returns the list of tasks it processed, and cmd_run_loop maps a
terminal failure state (BLOCKED or FAILED) to exit code 1, printing each failing
task. An empty queue is still exit 0 - an idle run is not a failure.
